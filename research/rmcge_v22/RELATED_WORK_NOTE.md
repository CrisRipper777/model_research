# Related work note

This note locates V2.2 among established ideas. The listed papers motivate design choices; none establishes that this particular combination works on the current MAG datasets.

| Work | Verified record | Relation and boundary |
|---|---|---|
| Dynamic Edge-Conditioned Filters | Simonovsky & Komodakis, CVPR 2017, [CVF Open Access](https://openaccess.thecvf.com/content_cvpr_2017/html/Simonovsky_Dynamic_Edge-Conditioned_Filters_CVPR_2017_paper.html) | Generates feature filters from edge labels. This is edge-conditioned feature transformation, unlike scalar attention that only rescales an entire message. V2.2 uses receiver/sender state rather than edge labels and a low-rank diagonal gate; it is not a reproduction of ECC. |
| GNN-FiLM | Brockschmidt, ICML 2020, [PMLR](https://proceedings.mlr.press/v119/brockschmidt20a.html) | Target representation determines feature-wise modulation shared over incoming messages. M2 is the receiver-only special case; linearity allows its gate to commute with a sum aggregation. M3 adds sender-specific pair dependence, which cannot in general be moved after aggregation. |
| Heterogeneous Graph Transformer | Hu et al., WWW 2020, [arXiv](https://arxiv.org/abs/2003.01332), [DOI](https://doi.org/10.1145/3366423.3380027) | Uses node-type/edge-type dependent parameters for heterogeneous relation graphs. The current MAG has a shared product-node topology with Text/Visual attributes, not typed entities and relations; V2.2 conditions content on modality direction and endpoint representations instead of introducing relation-type parameter banks. |
| HGConv: Hybrid Micro/Macro Level Convolution | Yu et al., arXiv 2020, [arXiv](https://arxiv.org/abs/2012.14722) | Separates within-relation neighbor importance and across-relation weighting in heterogeneous graphs. V2.2 keeps the existing fixed product graph and studies feature-channel content within cross-modal messages; it does not introduce multiple relation channels. |
| MAGNN | Fu et al., WWW 2020, [arXiv](https://arxiv.org/abs/2002.01680), [ACM DOI](https://doi.org/10.1145/3366423.3380297) | Uses content transformation plus intra/inter-metapath aggregation and intermediate semantic nodes. V2.2 has no metapaths or typed intermediate nodes; only its broad motivation of preserving content while aggregating is shared. |
| Revisiting Heterophily for GNNs | Luan et al., NeurIPS 2022, [NeurIPS](https://papers.neurips.cc/paper_files/paper/2022/hash/092359ce5cf60a80e882378944bf1be4-Abstract-Conference.html) | Reconsiders graph-label homophily and proposes Adaptive Channel Mixing with aggregation, diversification and identity channels. It motivates not assuming every incoming signal should be smoothed identically, but does not directly test multimodal message content gating. |
| DMoN / Graph Clustering with GNNs | Tsitsulin et al., JMLR 2023, [JMLR](https://www.jmlr.org/papers/v24/20-998.html) | An unsupervised modularity objective for graph clustering/pooling. V2.2 does not add DMoN, MinCutPool, prototypes, or cluster losses: those would alter the graph/context and confound the focused content-modulation question. |
| MvCGE | Wu et al., NeurIPS 2025, [NeurIPS](https://proceedings.neurips.cc/paper_files/paper/2025/hash/7315c16422558ae81d65a812723d2cec-Abstract-Conference.html) | Multi-view collaborative experts use shared parameters and graph-aware routing. V2.2 inherits the project's shared expert-bank motivation, but its target is an edge-level cross-modal content residual, not a multi-view expert replacement. |
| RoleMAG | Zuo et al., arXiv:2604.12271 (2026), [arXiv preprint](https://arxiv.org/abs/2604.12271) | Learns neighbor roles for multimodal graph propagation. It is directly adjacent in problem framing. V2.2's four-arm sender/receiver/pair comparison is a narrow low-rank content mechanism; it does not learn role classes or route messages to role-specific propagation channels. The arXiv record is treated as a preprint, not evidence of a settled publication claim. |

## Where the mechanism adds capacity

An edge scalar `a_ij` produces `a_ij v_j`, preserving the direction of the sender vector: all channels are scaled together. Receiver-only FiLM computes `g_i ⊙ sum_j P_ij v_j`; because `g_i` is constant over incoming edges, it is algebraically equal to `sum_j P_ij (g_i ⊙ v_j)`. Pair conditioning computes `g(q_i,k_j) ⊙ v_j`, so the channel pattern can vary by both receiver and sender before messages are summed. That is the intended expressivity gap; the synthetic test verifies one such construction, not utility on real MAG data.

## Novelty boundary

Low-rank edge-conditioned filters, feature-wise modulation, and multimodal neighbor selection all predate this study. The candidate-specific contribution is the controlled placement of a shared low-rank pair-conditioned residual inside an existing physical shared-expert path, with M1/M2/M3 endpoint controls and an M4 V2.1-C1 interaction arm. No priority or novelty claim is made beyond this bounded implementation and experiment.
